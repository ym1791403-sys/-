# ✨ متجر الإكسسوارات النسائية - مربوط بقاعدة بيانات Firebase

المتجر متصل ومربوط مباشرة وبشكل حي (Real-time) بقاعدة بيانات **Firebase Firestore** الخاصة بمشروعكِ:
🔥 **Project ID:** `galgol`

---

## 🚀 الميزات بعد ربط Firebase:

1. **إدارة المنتجات مباشرة من وإلى Firebase:**
   - أي منتج تضيفينه من **"لوحة التحكم"** يُحفظ مباشرة في مجموعة `products` داخل فايربيس ويظهر فوراً لجميع الزوار بدون إعادة تحميل الصفحة!
   - إمكانية حذف أي منتج بضغطة زر من المتجر ويُحذف تلقائياً من قاعدة البيانات.
   - **بدون أي بيانات افتراضية:** المتجر يبدأ نظيفاً تماماً ومرتبطاً بمنتجاتكِ الحقيقية فقط.

2. **تسجيل ومتابعة الطلبات حياً (Orders Collection):**
   - عندما تقوم أي زبونة بإتمام طلب، تُحفظ تفاصيل الطلب بالكامل (الاسم، الهاتف، العنوان، المنتجات، الإجمالي) داخل مجموعة `orders` في Firebase.
   - تظهر كل الطلبات الواردة في تبويب **"الطلبات"** بلوحة التحكم مع إرسال الفاتورة تلقائياً عبر واتساب.

3. **حفظ إعدادات المتجر حياً (Settings/Store Document):**
   - رقم الواتساب، واسم المتجر، والحد الأدنى للشحن المجاني، تُحفظ في Firebase وتتزامن تلقائياً على كل الأجهزة.

---

## 🔒 تنبيه هام بخصوص قواعد أمان فايربيس (Firestore Security Rules):

للسماح للمتجر بالقراءة وحفظ المنتجات والطلبات دون قيود، تأكدي من ضبط قواعد Firestore في لوحة تحكم Firebase:
1. افتحي وحدة تحكم فايربيس: [Firebase Console](https://console.firebase.google.com/)
2. اختاري مشروع **galgol**.
3. ادخلي على **Build** ثم **Firestore Database**.
4. اضغطي على تبويب **Rules (القواعد)**، وضعي الكود التالي:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```
5. اضغطي على **Publish (نشر)**.
