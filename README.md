# ✨ متجر Chic Shop Galena's للإكسسوارات النسائية

متجر إلكتروني فاخر وسريع للإكسسوارات النسائية والمجوهرات المطلية، متصل ومربوط مباشرة وبشكل حي (Real-time) بقاعدة بيانات **Firebase Firestore** الخاصة بمشروعكِ:
🔥 **Project ID:** `galgol`

---

## 📁 هيكلية المشروع وتقسيم الملفات (Project Structure):

تم تقسيم المتجر إلى معمارية نظيفة ومنظمة واضحة تفصل بين الباك إند (Backend) والفرونت إند (Frontend) ومكونات React:

## 🚀 ميزات المتجر بعد التنظيم:

1. **تقسيم معياري كامل (Modular Components):**
   - كل جزء من الموقع أصبح في ملف مستقل يسهل تعديله وتطويره بشكل أسرع دون أخطاء.
2. **اتصال حي مباشر مع Firebase:**
   - المنتجات والطلبات والإعدادات تتزامن حياً على جميع الأجهزة دون الحاجة لإعادة تحميل الصفحة.
3. **التواصل عبر تيك توك وواتساب:**
   - تم ربط حساب تيك توك الرسمي (`https://www.tiktok.com/@jaljola2?_r=1&_t=ZS-9BReZO7XDVs`) ورقم الواتساب في كافة أرجاء المتجر.
4. **تجاوب كامل مع كافة الشاشات:**
   - يعمل بسلاسة فائقة على الهواتف، التابلت، اللابتوب، والشاشات الكبيرة.
5. **رفع الصور من الجهاز مباشرة:**
   - إمكانية سحب وإفلات أو اختيار الصور من الهاتف أو الكمبيوتر مباشرة مع ضغط الحجم تلقائياً.

## 💻 طريقة تشغيل المتجر محلياً:

### الطريقة الأولى (الأسهل على Windows):
- اضغطي ضغطتين فقط على ملف **`start.bat`**، سيقوم بتشغيل السيرفر وفتح المتصفح تلقائياً على المتجر!

### الطريقة الثانية (عبر موجه الأوامر Terminal):
```bash
python server.py
```
ثم فتح الرابط: **http://127.0.0.1:5000**
