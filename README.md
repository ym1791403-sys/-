# ✨ متجر Chic Shop Galena's للإكسسوارات النسائية

متجر إلكتروني فاخر وسريع للإكسسوارات النسائية والمجوهرات المطلية، متصل ومربوط مباشرة وبشكل حي (Real-time) بقاعدة بيانات **Firebase Firestore** الخاصة بمشروعكِ:
🔥 **Project ID:** `galgol`

---

## 📁 هيكلية المشروع وتقسيم الملفات (Project Structure):

تم تقسيم المتجر إلى معمارية نظيفة ومنظمة واضحة تفصل بين الباك إند (Backend) والفرونت إند (Frontend) ومكونات React:

```
aura-accessories/
│
├── backend/                       # السيرفر وخدمات الباك إند
│   ├── server.py                 # سيرفر Flask واستضافة الملفات وإدارة الـ APIs
│   ├── requirements.txt          # مكتبات Python المطلوبة
│   └── data/                     # حفظ الطلبات المحلي (Fallback)
│
├── frontend/                      # واجهة المتجر والفرونت إند
│   ├── index.html                # صفحة المتجر الرئيسية
│   ├── privacy.html              # صفحة سياسة الخصوصية والشروط والأحكام والاسترجاع
│   ├── css/
│   │   └── styles.css            # ملف التنسيقات والمؤثرات البصرية والفخامة
│   └── js/
│       ├── config/
│       │   └── firebase.js       # إعداد وربط Firebase Firestore والتحليلات
│       ├── constants/
│       │   └── storeData.js      # أقسام المتجر، أسعار الشحن، والإعدادات الافتراضية
│       ├── components/           # مكونات React المنفصلة
│       │   ├── Toast.js          # إشعارات التنبيه
│       │   ├── Header.js         # رأس الصفحة وشريط الإعلانات والبحث
│       │   ├── Hero.js           # واجهة البنر الرئيسية الكبيرة المتجاوبة
│       │   ├── CategoryFilter.js # تصنيفات المتجر
│       │   ├── ProductCard.js    # كارت المنتج الفردي
│       │   ├── ProductGrid.js    # شبكة عرض المنتجات ومعلومات الشحن
│       │   ├── QuickViewModal.js # نافذة المعاينة السريعة وتحديد الألوان
│       │   ├── CartDrawer.js     # سلة المشتريات الجانبية وحساب الشحن المجاني
│       │   ├── WishlistDrawer.js # قائمة المفضلة
│       │   ├── CheckoutModal.js  # نافذة إتمام الطلب وتحديد المحافظة
│       │   ├── OrderSuccessModal.js # شاشة نجاح الطلب مع الاحتفال (Confetti)
│       │   ├── AdminModal.js     # لوحة التحكم والإدارة (منتجات، طلبات، إعدادات)
│       │   ├── PolicyModal.js    # نافذة تفاعلية للسياسات (خصوصية، استبدال، شروط، شحن)
│       │   ├── FloatingActions.js # الزر العائم لتيك توك وترس الإدارة
│       │   └── Footer.js         # تذييل الصفحة وروابط السياسات وواتساب المطور JOO
│       └── app.js                # التطبيق الرئيسي وتنسيق الحالة وربط المكونات
│
├── vercel.json                   # إعدادات النشر على Vercel وروابط التوجيه النظيفة
├── privacy.html                  # محول تلقائي لصفحة السياسات
├── start.bat                     # تشغيل المتجر بضغطة زر واحدة على Windows
├── server.py                     # مشغل السيرفر السريع من المجلد الرئيسي
├── index.html                    # محول تلقائي إلى frontend/
├── README.md                     # التوثيق
└── .gitignore                    # الملفات المستثناة من Git
```

2. **ربط المطور المباشر بنفس أسلوب وتصميم كيان سيتي:**
   - تم ضبط عبارة `Developed by JOO` في الفوتر لترتبط مباشرة برقم واتساب المطور (`https://wa.me/201095046646`) لفتح المحادثة فورياً بدون كتابة الرقم الصريح في الصفحة حفاظاً على الشكل الجمالي.
3. **حفظ الطلبات تلقائياً في Firebase Firestore:**
   - تسجيل طلبات العملاء بكامل التفاصيل داخل قاعدة البيانات وعرض رسالة النجاح والاحتفال مباشرة دون وسيط.
4. **تجاوب كامل مع كافة الشاشات:**
   - يعمل بسلاسة فائقة على الهواتف، التابلت، اللابتوب، والشاشات الكبيرة.
5. **رفع الصور من الجهاز مباشرة:**
   - إمكانية سحب وإفلات أو اختيار الصور من الهاتف أو الكمبيوتر مباشرة مع ضغط الحجم تلقائياً.

## 💻 طريقة تشغيل المتجر محلياً:

### الطريقة الأولى (الأسهل على Windows):
- اضغطي ضغطتين فقط على ملف **`start.bat`**، سيقوم بتشغيل السيرفر وفتح المتصفح تلقائياً على المتجر!

### الطريقة الثانية (عبر موجه الأوامر Terminal):
```bash
python server.py
```
ثم فتح الرابط: **http://127.0.0.1:5000**
